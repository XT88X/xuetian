# 07 · 快速上手

## 环境准备

| 依赖 | 版本 | 说明 |
|------|------|------|
| ESP-IDF | 5.5.x（推荐 5.5.3） | 框架本体 |
| Python | 3.10+ | 工具脚本用 |
| FFmpeg | 任意 | 重采样语音资源时用 |
| USB 转串口 | CH340 / CP2102 | 烧录用 |

### 安装 ESP-IDF

```bash
# macOS / Linux（ESP-IDF 官方安装脚本）
mkdir -p ~/esp
cd ~/esp
git clone -b v5.5.3 --recursive https://github.com/espressif/esp-idf.git
cd esp-idf
./install.sh
source ~/esp/esp-idf/export.sh

# Windows 用官方 ESP-IDF Tools 安装器
```

## 获取源码

```bash
cd ~/esp
git clone https://github.com/LuwuDynamics/rig_omni.git RIG-Omni
cd RIG-Omni
```

## 配置板型和选项

```bash
# 先设目标芯片为 ESP32-S3
idf.py set-target esp32s3

# 打开菜单配置
idf.py menuconfig
```

在菜单里选：

```
└─ RIG-Omni Configuration
   ├─ Board Type
   │   ├─ RIG-Puppy      ← 选一个
   │   ├─ RIG-Hover
   │   ├─ RIG-Arm
   │   └─ RIG-Tars
   ├─ Firmware Region
   │   ├─ Domestic (China)
   │   └─ Overseas
   ├─ Select display style
   │   └─ Emote animation style
   ├─ Flash Assets         ← 要勾上
   └─ Flash Emote Assets   ← 要勾上
```

### Puppy 配置文件路径参考

如果选 Puppy，引脚定义在 `main/boards/puppy/board_config.h`：

```cpp
// 需要对照你的硬件版本修改
#define MOTOR_UART_TX_PIN     48
#define MOTOR_UART_RX_PIN     14
#define DISPLAY_MOSI_PIN      11
#define DISPLAY_CLK_PIN       12
#define DISPLAY_CS_PIN        10
// ...等等
```

## 编译

```bash
idf.py build
```

编译时间：第一次大概 10-20 分钟（看电脑性能）。成功后输出：

```
Project build complete. To flash, run:
 idf.py -p /dev/ttyUSB0 flash
```

## 烧录

```bash
# Windows COM 口
idf.py -p COM3 flash monitor

# macOS
idf.py -p /dev/cu.usbmodem2101 flash monitor

# Linux
idf.py -p /dev/ttyUSB0 flash monitor
```

`monitor` 会自动打开串口监视器（按 Ctrl+] 退出）。

### 只烧资源（不改 App）

```bash
idf.py build
# 资源镜像在 build/spiffs.bin
esptool.py --chip esp32s3 --port /dev/ttyUSB0 \
    write_flash 0x210000 build/spiffs.bin
```

## 第一次启动

1. 通电后屏幕显示开机表情 + 音效
2. 如果没有配置过 WiFi → 屏幕显示配网二维码
3. 用手机扫二维码或通过 App 配网
4. 连接成功后固件自动检查 OTA、连接云端
5. 说唤醒词（"你好" / "Hey Kira"）开始对话

## 烧写时常见问题

### 找不到 /dev/ttyUSB0

- Linux：先 `ls /dev/ttyUSB*` 看看
- macOS：可能叫 `/dev/cu.usbserial-*` 或 `/dev/cu.usbmodem-*`
- Windows：设备管理器里看 COM 编号
- 如果完全没有：检查 USB 线是否支持数据（很多线只充电）

### 烧写失败 ESPP_ERR_OPEN_WRITE_FLASH

`idf.py set-target esp32s3` 之后再烧。或者手动进入下载模式：按住 BOOT 键点一下 RST 键再松开。

### 串口打印乱码

波特率不对。monitor 用 115200 就行。

### WiFi 连不上

第一次启动必须配网。长按 BOOT 键 3 秒重置 NVS，然后重来。

## 发布打包

批量生成多板型多区域固件：

```bash
# Dry run，只看会打包什么
python3 tools/package_luwu_firmware.py --board tars --dry-run

# 实际打包（多板型可以逗号分隔）
python3 tools/package_luwu_firmware.py --board puppy,hover,arm,tars
```

输出在 `releases/Luwu-Tools/bin/`：

```
releases/
└─ Luwu-Tools/bin/
   ├── RIG/
   │   ├── puppy/
   │   ├── hover/
   │   ├── arm/
   │   └── tars/
   └── GARAGE/          ← 硬件测试固件
```

## 调试技巧

### 串口日志级别

```bash
idf.py menuconfig
→ Component config → ESP Logging → Default log verbosity
# Debug / Info / Warn / Error
```

### 日志过滤

```bash
idf.py monitor | grep MCP       # 只看 MCP 相关
idf.py monitor | grep -E "PUPPY|HOVER"
```

### CMake 工具链调试

```bash
idf.py reconfigure     # 修改了 CMakeLists.txt 或 Kconfig 后跑一下
idf.py fullclean       # 全清重新编
```
