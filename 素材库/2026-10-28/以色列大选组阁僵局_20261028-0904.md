# 以色列第26届议会选举出口民调出炉：两大阵营均未过半，前军方总参谋长埃森科特宣布准备组阁

> 以色列大选组阁僵局 | 收集时间：2026-10-28 09:04

## 一、事件概述

以色列第26届议会选举于当地时间10月27日7时至22时举行，全境约1.2万个投票站开放，约730万名合格选民投票，出口民调显示投票率创下数十年来新高。当晚公布的初步结果显示，现任总理内塔尼亚胡领导的右翼宗教政党阵营预计获得50席，而前国防军总参谋长加迪·埃森科特领导的反内塔尼亚胡阵营预计获得52至53席，阿拉伯裔政党预计获得17至18席并创历史新高。全部120席中，两大阵营均未达到组阁所需的61席多数。埃森科特当晚发表声明称，结果反映了对内塔尼亚胡政府"完全丧失信心"，宣称这是"以色列主流犹太多数的胜利"，并将立即推动"执行人民决定、替换内塔尼亚胡政府"。不过其阵营此前已排除与阿拉伯政党合作，而反对派内部在巴以问题、宗教政策上分歧明显；内塔尼亚胡阵营则被曝曾提出与埃森科特联合组阁但遭拒。正式计票结果预计11月4日公布。

## 二、关键信息点

- 时间：投票时间2026年10月27日7时—22时（当地时间）；出口民调当晚公布；初步计票结果预计11月4日揭晓
- 地点：以色列全境（耶路撒冷、特拉维夫等）
- 主要当事方：现任总理内塔尼亚胡及其领导的利库德集团；前国防军总参谋长埃森科特领导的中间派政党"正直党"；前总理纳夫塔利·贝内特领导的团结党；阿拉伯裔政党联盟"联合名单"与"阿拉伯宗教运动"党；以色列总统赫尔佐格
- 事件性质：选举结果与组阁僵局 / 国际政治
- 当前进展：出口民调阶段，尚无明确赢家。总统将磋商并委托最有可能组阁者组建政府，获授权者最多有42天争取其他政党支持；失败可由他人再试，新政府产生前现政府以看守政府身份履职。若僵局持续，以色列可能再次大选（2019年至2022年间曾三年半内五次选举）。

## 三、影响力分析

- 传播热度：高。新华社、中新网、国际在线（总台环球资讯）均以专稿跟进，中文媒体在10月27日晚至28日早间密集推送，路透社、美联社、CNN（美国有线电视新闻网）、《金融时报》《华盛顿邮报》《卫报》同步报道。
- 影响范围：国际 + 中东地缘政治。这是2023年10月7日新一轮巴以冲突爆发以来以色列首次议会选举，直接牵动加沙局势、对伊朗军事对抗与国内政治分歧；同时作为美国中东盟友的关键变量，关系美以关系与地区力量格局。
- 舆论倾向：分歧明显但普遍聚焦"没有赢家"。西方媒体多认为内塔尼亚胡阵营遭"重大打击"（席位较2022年64席降至约50席），但路透社分析认为僵局反而可能对内塔尼亚胡有利；中国媒体普遍强调"选举僵局不改变安全政策基本盘"。
- 突出特点：反转性强——曾被普遍视为"内塔尼亚胡稳赢"的一战，主流竟双双不过半；戏剧性足——前军方总参谋长变身挑战者、幕后组阁主角；不确定性高——阿拉伯政党首次成为关键摇摆力量，且两大领袖均已排除与之合作，形成结构性死结；历史意义大——内塔尼亚胡若下台，将终结其近二十年连续执政格局。

1. **方向名称：一场谁都没赢的选举**
   - 角度说明：用"两大阵营双双不过半"这一反常识结果切入，梳理席位分布、算票逻辑与61席门槛，讲清什么叫"组阁僵局"，适合做事件复盘。
   - 适用形式：深度长文 / 图解短视频
   - 目标受众：国际新闻读者、对以色列与中东局势有基础兴趣的读者

2. **方向名称：军人转政坛，为什么是埃森科特**
   - 角度说明：梳理埃森科特从国防军总参谋长到政党领袖、这次选举最大赢家的身份转换，分析其"国安底色"与政治新手的反差，以及"完成兵役义务"等竞选承诺的含义。
   - 适用形式：人物特稿 / 短视频人物解读
   - 目标受众：军事与政治类读者、以色列及中东方向关注者

3. **方向名称：内塔尼亚胡会下台吗**
   - 角度说明：结合议会制"委任—授权—组阁"流程、42天期限、看守政府规则与联合组阁可能性，分析他在没有多数的情况下继续执政的路径与条件。
   - 适用形式：评论 / 深度长文
   - 目标受众：政治学爱好者、财经与地缘研究读者

4. **方向名称：首次成为关键票仓的阿拉伯政党**
   - 角度说明：解释阿拉伯裔政党席位创历史新高的意义，以及两大阵营同时排除与其合作所造成的组阁悖论，可延伸讨论族群政治对以色列社会的长期影响。
   - 适用形式：科普图文 / 分析视频
   - 目标受众：中东研究读者、族裔与少数议题关注者、高校学生

5. **方向名称：换一个总理，加沙会不同吗**
   - 角度说明：对比内塔尼亚胡与埃森科特在伊朗威胁、军事安全、巴勒斯坦建国问题上的立场重合度，参考欧洲对外关系委员会分析，指出政权更替未必带来安全政策转向，但国内改革方向可能明显调整。
   - 适用形式：深度评论 / 短视频解读
   - 目标受众：关注中东局势与能源安全的读者、国际关系专业读者

6. **方向名称：三年半五次选举，以色列政治为何总是谈崩**
   - 角度说明：回顾2019—2022年的选举周期与2021年短暂联合政府的瓦解，解释比例代表制、小党门槛（部分政党支持率接近3.25%）如何让组阁反复流产。
   - 适用形式：科普长文 / 动画短视频
   - 目标受众：制度与政治学爱好者、通俗历史科普读者
