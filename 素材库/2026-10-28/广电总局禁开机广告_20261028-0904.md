# 国家广播电视总局发布两项新规：开机不得播放广告，电视开机直达全屏直播

> 广电总局禁开机广告 | 收集时间：2026-10-28 09:04

## 一、事件概述

10月27日，国家广播电视总局公布《有线广播电视运营服务管理规定》《交互式网络电视运营服务管理暂行规定》两项规定，均自2026年11月27日起施行。规定围绕"直播优先"原则，对有线广播电视运营服务和交互式网络电视（IPTV，即互联网协议电视）运营服务提出明确要求：必须实现开机看全屏直播、设置频道回看入口、不得播放开机广告；智能电视机应支持优先呈现直播频道功能并提供便捷设置入口；应向用户提供便捷设置，方便自行选择开机进入直播或者电视交互主页；首页须设立免费专区并对优质免费内容重点推荐，精简收费栏目数量，明示节目收费信息，规范应用专区运营和订购支付管理。此外还要求持续优化终端性能、缩短开机时长，简化遥控操作并实现遥控器一键切换直播信源，鼓励采用语音遥控、手机遥控、人工智能等新技术，同时建立用户投诉处理机制。新规把"开机第一屏"的主导权重新交还给直播频道，对长期依赖开机广告变现的运营商构成直接冲击。

## 二、关键信息点

- 时间：2026年10月27日对外公布；2026年11月27日起正式施行
- 地点：中国全国
- 主要当事方：国家广播电视总局；有线广播电视运营服务商；交互式网络电视运营服务商；智能电视机厂商；广大电视用户
- 事件性质：政策 / 行业监管规定（民生类）
- 当前进展：规定已正式公布，进入生效倒计时。各运营商与终端厂商需在11月27日前完成直播优先改造、首页免费专区设置、开机广告清理与用户投诉机制建立。央视新闻、求是网、中国网、中新经纬等已集中解读，央视网"8点见"栏目将其列为当日要闻。

## 三、影响力分析

- 传播热度：高。央视新闻以"新规来了！不得播放开机广告 看电视更省心"为题推送，央视网"8点见"、求是网早报、中国网、中新经纬等同步转载，并与"蛟龙"号完成7000米级海试并列为当日头条。
- 影响范围：国内。覆盖有线电视与交互式网络电视的数亿终端用户、广电运营商、网络电视平台、智能电视品牌商以及依赖开机广告的中小广告主，属于广电行业格局性变量。
- 舆论倾向：整体正面。多数网民认为"终于不用看开机广告了""更符合付费体验"；行业侧关注点转向开机广告收入缺口如何填补，运营商将重新评估免费内容与会员体系的价值关系。
- 突出特点：切口小、痛感强——"开机广告"几乎是所有电视用户都遇到过的日常槽点，属于低门槛、高共鸣的典型选题；同时它并非单纯的福利式通知，而是牵动运营商收入结构与终端厂商系统改造能力的硬性规定，既有情绪价值又有行业研究价值。

## 四、可创作方向

1. **方向名称：开机那十几秒，谁在替你做决定**
   - 角度说明：以"用户被强制观看的十几秒"为切口，量化开机广告对时间、情绪与消费决策的侵占，把一条监管规定还原成每个人都能感知的日常体验，容易引发共鸣与转发。
   - 适用形式：短视频 / 图文短文
   - 目标受众：普通电视用户、家庭消费决策者、内容创作者

2. **方向名称：这份新规到底改了什么，一句话说清**
   - 角度说明：逐条拆解"直播优先""不得播放开机广告""首页免费专区""明示收费信息""一键切换直播信源"等条款，说明这些条款如何落到机顶盒和智能电视的实际界面上，适合做政策科普。
   - 适用形式：图文长文 / 政策科普短视频
   - 目标受众：关注公共政策的中年用户、家庭数码设备决策者、电视行业从业者

3. **方向名称：开机广告的钱从哪来，谁来接盘**
   - 角度说明：分析开机广告的商业模式与营收规模，探讨运营商在广告收入受限后如何通过会员、增值服务与免费内容引流填补缺口，剖析"内容免费+服务收费"的新平衡。
   - 适用形式：深度长文 / 商业评论
   - 目标受众：传媒与广告从业者、财经类读者、行业研究者

4. **方向名称：智能电视的"第一屏争夺战"**
   - 角度说明：从终端厂商视角观察硬件开机流程、直播信号优先级与遥控器交互的改造要求，讨论AI（人工智能）语音遥控、手机遥控等新技术如何重塑电视入口与家庭大屏场景。
   - 适用形式：深度长文 / 行业观察视频
   - 目标受众：科技行业读者、智能家居与消费电子爱好者、创业者

5. **方向名称：11月27日之后，家里的电视会变成什么样**
   - 角度说明：做一份"规则改变后家庭观看场景"的生活化推演，从老人使用遥控、孩子看动画、年轻人点播的差异出发，展示新规落地后家庭大屏使用的真实变化。
   - 适用形式：图文 / 街采短视频 / 图解
   - 目标受众：家庭用户、亲子类账号读者、电视行业从业者
