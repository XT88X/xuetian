# 中国等26国签署《联合国可转让货物单证公约》

> 联合国货物单证公约 | 收集时间：2026-10-27 21:05

## 一、事件概述

当地时间2026年10月26日，《联合国可转让货物单证公约》（又称《阿克拉可转让货物单证公约》）签约仪式在加纳首都阿克拉举行，共有60余个国家和地区代表团、约400人参加。中国商务部副部长蒋成华出席仪式并代表中国政府签署公约，包括中国、加纳在内的26个国家成为首批签约国。该公约由中国发起并引领达成，经第80届联合国大会于2025年12月15日审议通过（决议A/RES/80/162），此后将在纽约联合国总部继续开放供各国签署。公约的核心，是在国际规则层面创设适用于所有跨境运输方式的"可转让货物单证"（NCD，Negotiable Cargo Document），赋予铁路运单、公路运单等传统运输单证类似海运提单的物权凭证功能，打破数百年来只有海运提单才能代表货权的制度壁垒，被视为国际商事规则领域具有里程碑意义的创新。

## 二、关键信息点

- 时间：2026年10月26日签约仪式；公约于2025年12月15日经联合国大会通过
- 地点：加纳首都阿克拉；后续在纽约联合国总部开放签署
- 主要当事方：中国、加纳等26个首批签约国；联合国国际贸易法委员会（UNCITRAL）；中国商务部副部长蒋成华
- 事件性质：国际规则制定 / 全球贸易治理 / 制度型开放
- 当前进展：26国完成首批签署，公约将在满足生效条件后生效，并继续在纽约开放签署

## 三、影响力分析

- 传播热度：新华社、央视新闻、商务部、重庆市政府及联合国贸法会官网同步发布；"中国提案变成联合国公约""重庆策源地"成为财经舆论关注点
- 影响范围：全球跨境贸易与多式联运、铁路与公路运输融资、陆上贸易规则、中国中欧班列与西部陆海新通道
- 舆论倾向：普遍肯定其填补国际规则空白、降低中小企业贸易融资门槛；也有观点关注公约生效进度、各国国内法衔接及电子单证安全问题
- 突出特点：这是首次在国际层面为所有运输方式创设可转让货物单证制度，且由中国发起并引领达成，策源于重庆；对长期受制于海运提单规则的陆上贸易具有结构性突破意义

## 四、可创作方向

- **方向名称：一张"铁路提单"如何改写四百年贸易规则**
  - 角度说明：从海运提单的物权凭证历史讲起，用中欧班列案例解释为何铁路运单长期不能押汇融资，以及NCD如何补上这一制度缺口
  - 适用形式：深度长文 / 动画科普
  - 目标受众：外贸从业者、物流与金融读者

- **方向名称：从重庆提案到联合国公约**
  - 角度说明：梳理重庆在西部陆海新通道、铁路提单实践中的探索，还原中国方案进入联合国贸法会议程并最终成为公约的路径
  - 适用形式：纪实长文 / 纪录片式短视频
  - 目标受众：政策研究者、区域经济关注者

- **方向名称：中小企业出海的"融资难"有新解吗**
  - 角度说明：以NCD可转让、可质押的特性为切口，测算其对跨境中小企业现金流与融资成本的可能影响，并提示银行落地条件
  - 适用形式：财经评论 / 数据可视化
  - 目标受众：中小企业主、金融机构从业者

- **方向名称：26国签署之后，公约离生效还有多远**
  - 角度说明：解释国际公约"签署—批准—生效"的流程，跟踪主要贸易国的批准进度与国内法衔接难点
  - 适用形式：政策解读 / 跟踪报道
  - 目标受众：国际贸易与法律从业者

- **方向名称：电子单证时代的物权凭证安全吗**
  - 角度说明：讨论NCD电子化后的唯一性、防篡改、跨境互认与数据主权问题，连接区块链提单等现有实践
  - 适用形式：科技评论 / 圆桌对谈
  - 目标受众：金融科技、供应链科技从业者
