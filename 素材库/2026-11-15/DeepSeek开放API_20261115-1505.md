# DeepSeek开放全家桶应用API：官方App能力首次全面拆包，开发者可1:1复刻

> DeepSeek开放API | 收集时间：2026-11-15 15:05

## 一、事件概述

2026年11月13日，国产大模型公司深度求索（DeepSeek，深度求索）宣布开放全家桶应用API（API，Application Programming Interface，应用程序编程接口）：官方App内的联网搜索、深度思考搜索、文件上传、链接阅读等对话能力，均可通过在原有API中开启对应参数直接调用；语音及相关底层能力也首次开放独立接口，涵盖OCR（光学字符识别）、ASR（自动语音识别）、TTS（文本转语音）等模块，支持单独或组合调用、分别计费。开发者由此可以在自己的产品中1:1复刻出完整的DeepSeek App。

根据DeepSeek官方更新日志，联网搜索能力通过新增的 deepseek_web_search 工具实现：在非思考模式下，模型可根据提问自动发起网页或图片搜索并附引用作答；在思考模式下，模型可在多步推理过程中自主联网检索，实现“深度思考搜索”。价格方面，DeepSeek以约五折的语音调用价格主打成本优势，并同步开源了一套聊天前端Demo（演示程序），降低开发者的接入门槛。目前开放平台提供 deepseek-flash 与 deepseek-v4-pro 等模型选项，最大输出长度达384K（38.4万token，词元），并兼容JSON Output、Tool Calls（工具调用）、Responses API 及 Anthropic 兼容接口。

消息公布后迅速在开发者社区刷屏，智源社区等平台将其标注为“突发”置顶，业界普遍认为此举大幅降低了“搜索+推理+语音”多模态（Multimodal，多模态）Agent（智能体）应用的开发门槛，被视为国产AI公司在生态开放路线上的一次标志性动作。
