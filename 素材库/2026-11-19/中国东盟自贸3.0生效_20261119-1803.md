# 中国—东盟自贸区3.0版升级议定书将于12月1日正式生效

> 中国东盟自贸3.0生效 | 收集时间：2026-11-19 18:03

## 一、事件概述

2026年11月16日，第29次中国—东盟领导人会议在菲律宾马尼拉宣布，中国—东盟自由贸易区（FTA）3.0版升级议定书将于2026年12月1日正式生效实施。该议定书于2025年10月28日在马来西亚吉隆坡签署，在既有经贸合作基础上新增数字经济、绿色经济、供应链互联互通、竞争和消费者保护、中小微企业5大领域，形成9大领域合作框架。数字经济方面，双方承诺暂免电子传输关税、保障数据跨境流动，并推动电子签名、电子支付、人工智能（AI）合作；绿色经济方面确立绿色贸易、绿色投资、循环经济、可持续金融、绿色技术、绿色标准、可持续能源、数字化绿色化协同8大优先合作领域；供应链方面首次设立专章，强化关键产品自由流通、基础设施互联互通与风险预警。议定书生效需中国和至少5个东盟成员国完成国内核准程序。

## 二、关键信息点

- 时间：2026年11月16日宣布；2026年12月1日正式生效；2025年10月28日签署
- 地点：菲律宾马尼拉（宣布地）/ 马来西亚吉隆坡（签署地）
- 主要当事方：中国、东盟10国、中国商务部
- 事件性质：区域经贸协定 / 制度型开放 / 政策落地
- 当前进展：中英文本已公布，双方正推进国内核准与实施准备；生效门槛为中国及至少5个东盟成员国批准

## 三、影响力分析

- 传播热度：11月19日中国网、经济日报等媒体集中解读，财经与国际关系圈关注“制度型开放”新样本。
- 影响范围：中国与东盟十一国的贸易投资、数字与绿色产业、区域供应链布局；企业市场准入与原产地合规。
- 舆论倾向：整体正面，强调反对贸易保护主义、深化区域合作；企业更关注数据跨境、原产地规则与标准互认的操作细则。
- 突出特点：在区域自贸协定中较早系统纳入数字、绿色与供应链规则；在贸易保护主义抬头背景下具标志性；2026年前三季度中国—东盟贸易额达5.57万亿元、同比增长9.6%，为生效提供现实热度。

   - 目标受众：外贸企业、政策关注者

3. **绿色经济8大优先领域：新能源企业如何布局东盟**

   - 适用形式：出海指南 / 企业案例
   - 目标受众：新能源与制造业企业

4. **供应链专章：中国企业的区域布局新逻辑**
   - 角度说明：结合“关键产品自由流通”和风险预警机制，讨论企业如何合规进行区域供应链重构。

5. **中小微企业的政策红利：如何用原产地规则降成本**

   - 适用形式：实操科普 / 直播课
   - 目标受众：中小外贸企业主
