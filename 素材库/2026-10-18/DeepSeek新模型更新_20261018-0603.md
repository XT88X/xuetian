# DeepSeek 上线 V4.1-Flash-1017 新模型并开放自研搜索 API

> DeepSeek新模型更新 | 收集时间：2026-10-18 06:03

## 一、事件概述
2026年10月17日下午，中国人工智能（AI，人工智能）公司 DeepSeek（深度求索）在官方平台发布新一代模型 DeepSeek-V4.1-Flash-1017（版本号以发布日期10月17日命名），其网页端、移动应用（APP，手机应用程式）与 API（Application Programming Interface，应用程序接口）模型已同步切换至该版本。此次更新的核心卖点是“许愿式”编程能力再升级——用户仅需较少提示词（Prompt）即可从零构建完整项目。与此同时，DeepSeek 宣布对外开放自研搜索服务，API 新增 Search（搜索）与 Fetch（抓取）两个接口，均为每千次5元。官方称该搜索引擎为“AI 原生”的通用搜索引擎，长期支撑其网页端与 API 端搜索，每天稳定处理全球数亿次搜索请求，索引全球千亿级网页，支持多语言实时检索，并对 SEO（Search Engine Optimization，搜索引擎优化）作弊、GEO（Generative Engine Optimization，生成引擎优化）操纵和低质 AIGC（AI Generated Content，人工智能生成内容）进行严格过滤。消息发布后，大量开发者在社交平台“排队点赞”，评价“这版真香”。

## 二、关键信息点
- 时间：2026年10月17日下午正式发布（上一代 V4.1-Flash 于2026年9月10日发布）
- 地点：线上发布（DeepSeek 总部位于中国杭州）
- 主要当事方：DeepSeek（深度求索）及其开发者用户、AI 行业竞争者
- 事件性质：科技突破/产品迭代
- 当前进展：网页端、APP 与 API 已同步切换至 V4.1-Flash-1017；Search 与 Fetch 接口正式向公众开放，定价5元/千次；据官方文档，Codex（代码生成工具）等能力当前对 DeepSeek API 用户免费，2026年10月31日16:00（UTC，协调世界时）起开始计费

## 三、影响力分析
- 传播热度：高。发布当日即在国内科技媒体与开发者社区形成刷屏，第一财经、羊城晚报等主流财经媒体跟进报道
- 影响范围：国内为主，波及国际 AI 行业与开发者生态，涉及大模型竞争格局、搜索入口与编程工具市场
- 舆论倾向：总体正面。网友对“性能提升同时成本下降”给予好评，关注点集中在“许愿式编程”与国产自研搜索
- 突出特点：一是“性能—费用”双优，多项基准测试（Benchmark）分数上扬的同时，任务运行时间与输出长度反而下降；二是首次开放自研搜索 API，直接切入搜索与内容生态；三是与当前 AI 编程工具（如 Cursor、Claude Code 等）形成正面竞争；四是其 KV Cache（键值缓存）大幅压缩，对 HBM（高带宽内存）需求降至约四分之一、对 SSD（固态硬盘）需求降至约八分之一，显著降低智能体（Agent）类任务成本
