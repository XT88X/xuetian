# 日本拟在《国家安全保障战略》中写入"无核三原则"例外条款

> 日本核武选项 | 收集时间：2026-11-05 18:05

## 一、事件概述

11月5日，日本共同社援引政府相关人士消息称，日本政府正研究在计划于年底修订的外交与安保纲领《国家安全保障战略》（National Security Strategy，NSS）中，明确写入"无核三原则"的例外条款。目前较有可能采用的方案，是写入"允许在紧急情况下向日本引进（运进）核武器"的相关主张，而暂不直接修改"无核三原则"本身。"无核三原则"即"不拥有、不制造、不引进核武器"，是日本战后核政策的基石，1967年由时任首相佐藤荣作提出，1971年获日本国会决议确认。此前，日本防卫大臣小泉进次郎11月3日已在东京一场研讨会上公开呼吁讨论调整"无核三原则"；多家日媒此前亦报道，首相高市早苗有意修改确认"无核三原则"的内阁决议，以强化美国对日的"延伸威慑"（即美国以包括核力量在内的军力保护盟友的安全承诺）。一旦相关表述写入NSS，将是日本战后核政策的一次重大松绑，预计将引发国内民意分裂以及国际社会尤其是亚洲邻国的强烈反应。

## 二、关键信息点

- 时间：2026年11月5日（共同社披露）；修订版NSS计划于2026年底出台
- 地点：日本东京（首相官邸及政府决策层）
- 主要当事方：日本政府（首相高市早苗、防卫大臣小泉进次郎）；美国（延伸威慑提供方）
- 事件性质：核政策调整 / 安全战略转向 / 高敏感争议议题
- 当前进展：处于政府内部研究阶段，倾向方案为写入"紧急情况下允许引进核武器"的例外主张，暂不动"无核三原则"条文本身；最终表述待年底NSS修订时确认
